# Handoff / Findings Template

Copy this for every research note and agent handoff. Structured, cited, terse.
Delete the instructions in parentheses when filling it in.

```markdown
# <Topic> — <research | analysis | handoff>
- Date: YYYY-MM-DD
- Author role: Scout | Builder | Evaluator | Lead
- Phase: research | analysis | implementation | testing
- Status: draft | reviewed | signed-off

## TL;DR
(2–4 bullets. What a reader needs before opening the detail.)

## Detail
(Headings + short bullets. Cited facts. No transcript dumps.)

## Decisions needed from operator
(Bullets, or "none".)

## Open questions
(Bullets, or "none".)

## Sources
- <title> — <url or tool> — <date accessed>

## Review log
- <role> <date>: <note>  (Evaluator appends sign-off here)
```

**Rules**
- If a section is empty, write "none" — don't delete it.
- Facts about the fast-moving RE landscape MUST be cited and dated.
- Keep it scannable. If it needs to be long, add a `## TL;DR` that stands alone.
